# 边注

边听边读的音乐故事原型。一首歌一张卡片，正文是这首歌写成时的笔记。播放只在页面里演示，标成 Apple Music，不接任何音乐服务。

静态页面，不用构建。用浏览器直接打开 `index.html`，或在这个目录里起一个本地服务器。

## 页面

- **阅读** 晚间一套故事卡。左右滑，或用上一则 / 下一则。圆钮切换播放和暂停。留下这篇会收进书签。阅读全文进入正文。
- **正在听** 完整笔记，播放条固定在下面。返回回到来的那一页。
- **书签** 留下的故事，最近的在前。可以打开，也可以移出。
- **目录** 七则按晚上的顺序排好，点一则回到那张卡。

## 给接着改的人

歌曲、笔记和版式都在 `js/app.js` 与 `css/app.css`。不要接 QQ 音乐、汽水音乐，也不要接 Apple Music 的真实接口。播放状态保持本地。
